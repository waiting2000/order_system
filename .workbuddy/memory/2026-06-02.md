# 2026-06-02 工作日志

## 家庭点菜系统 - 项目初始化

### 技术选型
- React 18 + Vite 5 + Tailwind CSS 3
- 数据持久化：**SQLite**（better-sqlite3），Express 后端，REST API
- 构建配置：`base: './'` + Express 静态文件服务（同一端口同时提供 API 和前端）

### v1.0 初始功能
1. **项目框架搭建**：Vite React 项目，Tailwind CSS 配置
2. **数据层**：MenuContext 全局状态管理，预设 4 道示例菜谱（红烧排骨、番茄炒蛋、酸辣汤、蛋炒饭）
3. **菜谱管理页面**：CRUD 完整流程（添加/编辑/删除），分类筛选，搜索，表单验证，图片预览
4. **菜单浏览页面**：分类标签切换，菜品卡片网格，点菜/取消点菜，今日菜单弹窗
5. **响应式设计**：手机端适配

### v1.3 切换为数据库管理
- **数据层**：MenuContext 从 localStorage 切换为 REST API（fetch），Express + SQLite 后端
- **数据库**：SQLite（better-sqlite3），WAL 模式，两张表 recipes + daily_orders，外键级联删除
- **API**：完整 REST 接口（CRUD 菜谱 + 点菜/取消/清空今日菜单）
- **启动命令**：`npm run start`（构建前端 + 启动 Express 服务器，监听 3001 端口）
- **前端适配**：保持相同 API 接口（addRecipe/updateRecipe/deleteRecipe/toggleTodayMenu 等现改为 async），页面无需修改
- **部署方式**：本地局域网（本机 IP 10.16.65.153:3001），家人同一 WiFi 即可访问
- **导入导出**保留：通过 API 逐条导入导出（备份用途）
- **开发模式**：Vite 开发服务器（3000）+ 代理 /api → 后端（3001），热更新

### v1.4 图片 Base64 存储
- **后端**：`express.json({ limit: '50mb' })`，支持大图 Base64 传输
- **前端表单**：新增文件上传按钮（`<input type="file" accept="image/*">`），FileReader 转 Base64 dataURL
- **交互**：点击按钮选择本地照片 → 自动转 Base64 → 预览缩略图；同时保留 URL 输入作为备选
- **限制**：前端限制 10MB/张，后端限制 50MB 请求体
- **存储**：数据库 `image` TEXT 字段直接存 `data:image/...;base64,...` 字符串
- **兼容**：`<img src={image}>` 同时支持 `data:` URL 和 `https:` URL，无需额外判断

### v1.5 家庭成员昵称 + 食材清单自动汇总
- **昵称**：首次打开弹窗设昵称，存 localStorage 可随时改；`daily_orders` 加 `nickname TEXT` 字段；今日菜单显示谁点了什么
- **采购清单**：底部新增「采购」Tab，按今日菜品自动合并食材；可逐项勾选 / 一键完成 / 重置，进度条显示完成度
- **数据层**：`todayMenu` 从 ID 数组改为 `todayOrders` 对象数组，携带 nickname 等订单信息
