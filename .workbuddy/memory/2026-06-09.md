# 2026-06-09

## 家年华改造 - 家庭综合应用 Hub

### 做了什么
将原"家庭点菜系统"改造为"家年华"家庭综合应用平台。

### 架构变化
- 采用「应用中心模式」：首页是 Hub，各功能以独立卡片呈现
- `App.jsx` 重构：顶层状态 `currentApp`（null=Hub, 'menu'=点单, 'notice'=备忘）
- 点单子应用通过 `MenuAppInner` 组件完整保留，Context 按需加载
- 新增 `HomePage.jsx`：Hub 首页，展示应用卡片
- 新增 `NoticeBoard.jsx`：家庭公告 + 个人待办模块

### 后端新增
- `server/routes/notices.js`：notices 表 CRUD 路由（GET/POST/PATCH/DELETE）
- db.js 通过 `CREATE TABLE IF NOT EXISTS` 自动建 notices 表
- server/index.js 注册 noticesRoutes

### 其他改动
- `index.html` 标题改为「家年华」，图标换为 🏠
- server/index.js 启动日志更新
- 安装了 react-router-dom（备用，当前用状态机路由）

### 当前模块
- 点单/菜谱（原有功能完整保留）
- 家庭备忘/公告（新建）

### 技术栈
React 18 + Vite 5 + Tailwind + Express + SQLite，服务端口 3001
